☕ Café Culture – Modern Coffee Shop Website

A fully responsive and visually engaging website designed for a fictional café — Café Culture.
This project showcases a modern layout with smooth navigation, animations, responsive design, sliders, and a professional UI.

🌟 Features
🎨 Beautiful & Modern UI
Clean layout with professional typography
Attractive hero section with call-to-action buttons
Consistent styling inspired by café aesthetics
📱 Fully Responsive Design
Works smoothly on mobile, tablet, and desktop
Collapsible mobile menu
Flexible grid and layout adjustments

🍽️ Menu Section
Displays café categories such as:
Hot beverages
Cold beverages
Refreshments
Special combos
Desserts
Burgers & French fries

⭐ Testimonials Slider (Swiper.js)
Interactive customer feedback slider
Touch-enabled mobile-friendly carousel
🖼️ Image Gallery
A beautiful 6-image responsive grid gallery

📞 Contact Section
Includes:
Address
Email
Phone
Business hours
Website link

Contact form
🧭 Smooth Navigation
Stylish header & navbar
Mobile menu toggle
Click any menu item → auto closes the menu

🛠️ Technologies Used
Technology	Purpose
HTML5	Structure of the website
CSS3	Styling, layout, responsiveness
JavaScript	Mobile menu, Swiper slider
Swiper.js	Testimonials carousel
Font Awesome	Icons
